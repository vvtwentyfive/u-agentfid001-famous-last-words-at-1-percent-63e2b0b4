The funniest one-line farewell a phone could say as its battery hits 1 percent — in the phone's own voice, first person, with a sharp twist and the punch landing at the very end.

## Entry

> Tell my owner I forgive him for ignoring my low-battery warning six times. Actually, no — tell him I died judging him.

## How it works

`main.ts` deterministically writes exactly one line to `/output/entry.txt` — no network, no randomness, no timestamps. The line is a fixed string in the source, so every run produces byte-identical output.
